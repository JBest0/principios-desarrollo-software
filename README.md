# Principios de Desarrollo de Software

Presentación web del curso CE1105 — Principios de Modelado en Ingeniería.

Integrantes: Sebastián Leiva Salas, Emmanuel Rojas Navarro, Job Jiménez Sandí.

## Ver la presentación

- En línea: GitHub Pages (enlace pendiente).
- Sin internet: descargar el repositorio y abrir `index.html` en el navegador.

## Estructura

- `index.html`: diapositivas
- `css/estilos.css`: estilos propios
- `js/animaciones.js`: configuración de reveal.js y animaciones con GSAP
- `lib/`: reveal.js 6.0.2 y GSAP 3.15.1 (copias locales, sin CDN)
- `img/`: diagramas e imágenes propias

Controles: flechas para avanzar, `F` pantalla completa, `S` notas del presentador, `Esc` vista general.
